# TaskFlow Flutter

Flutter-клієнт TaskFlow для Android та iOS. Початкова реалізація включає реєстрацію, вхід, вихід і перегляд дощок через .NET API.

Запуск на Android-емуляторі після `docker compose up -d --build` у корені репозиторію:

```powershell
flutter pub get
flutter run
```

Інструкція з адресами API й Docker: [docs/DEVELOPMENT.md](../docs/DEVELOPMENT.md). Структура клієнта та наступні функції: [docs/FRONTEND.md](../docs/FRONTEND.md).
